# کارگاه اصل جمع و ضرب

بازی‌های آموزشی ترکیبیات (اصل جمع و اصل ضرب) برای دانش‌آموزان.

نشانی صفحه: https://vahidzwork-ui.github.io/

- روی گوشی: لینک را در Safari (آیفون) یا Chrome (اندروید) باز کنید و با «Add to Home Screen» آیکون آن را روی صفحه‌ی اصلی بگذارید؛ بعد از اولین بار، بدون اینترنت هم باز می‌شود.
- برای به‌روزرسانی، فایل `index.html` را جایگزین کنید.
